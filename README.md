Тут короче наш супер пупер классный проект для VR, а именно практический курс по химии в виртуальной реальности. Использовался движок Unity со скриптами на C#.
Есть 2 билда: для демонстрации работы экспериментов на ПК и полноценный билд, работающий только с подключенным ВР.

Работают над этим челы из 4143(эт мы,да):

Папка Models нужна для сделанных моделей (Правильно? Правильно!).
Ваши шаги для того, чтобы было всё чики пуки:

	1. Делаете свою любимую модельку.
	
	2. Заливаете её в репозиторий в эту папку Models (со скрином рендера).
	
	3. Находите Issue, которое относится к этой модельке и кидаете туда скрин и закрываете Issue.
	
	4. Я это увижу и отмечу в проекте выполненную работу с ссылкой на папку в репоситории.
	
	5. Profit!
